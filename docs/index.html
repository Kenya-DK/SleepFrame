SleepFrame

How-to wiki

SleepFrame is a desktop automation companion for Warframe. Build macros visually in an n8n-style node editor, reuse methods, and share your macros with others. This page covers installing, building, and using it.

Rust + Tauri React + Tailwind Windows Node editor

Getting started

Requirements

  • Node.js 20+
  • Rust (stable)
  • WebView2 (preinstalled on Windows 10/11)

Run in development

npm install
npm run tauri dev

Build a release

npm run tauri build

Installers and binaries are written to src-tauri/target/release/bundle.

Settings and your macros are stored in %APPDATA%\com.sleepframe.app\settings.

The interface

  • Sidebar — your Macros and reusable Methods, the global hotkey, and Share/Import.
  • Canvas — the node graph for the selected macro. Click a macro to open it.
  • Right panel — configure the selected node (or the macro itself when nothing is selected).

Building a macro

  1. Pick a macro in the sidebar (or create a new one) and press Run / Start.
  2. Click + Add node to open the palette. Use the Search nodes… box to filter.
  3. Click an output port on the right of a node, then click another node to connect them. Click the small × on a link to remove it.
  4. Every node has an input (left) and one or more outputs (right). Flow nodes like Condition and Repeat have extra outputs.
  5. Drag one output to several nodes to run them as parallel branches.

Every macro starts from its Start node and follows the connections.

Node reference

Triggers

Start

Entry point of the macro. There should be exactly one.

End

Stops this branch of the workflow.

Inputs

Focus window

Brings a window to the foreground, nudges the cursor and clicks once. See Focus window.

Key down / Key up

Holds or releases a key or shortcut. Accepts combos like Ctrl+Shift.

Press key

Presses and releases a key once. Accepts combos like Ctrl+Space.

Shortcut

Fires a full key combination in one go, e.g. Alt+F4. Has a record button.

Hold key

Key down + wait + key up in one node, with a randomised hold duration.

Type text

Types a literal string. Supports the {{ocr}} placeholder.

Send messages

Types the next entry from an editable list of strings (sequential or random).

Click / Double click

Clicks a mouse button once, or double-clicks it.

Move mouse

Moves the cursor to a point or near the Warframe window centre. Has a position picker.

Timing

Wait

Waits a randomised time. Enable Countdown to show and notify a “next run” timer.

Flow

Condition

Routes execution based on a mode. See Condition modes.

Repeat

Repeats the connected body. Times 0 = forever; add an interval to repeat every X time.

Methods

Call method

Runs one of your reusable methods.

Method timer

Runs a method repeatedly in the background on its own interval.

Output

Notification

Shows a desktop notification.

Tip: any output port can have several links — they all run together as parallel branches.

Reusable methods

Methods are named sub-graphs you can call from any macro, or run on their own timer. Manage them in the Methods section of the sidebar.

  • Create a method with the inline New field; open it to edit its nodes.
  • In a macro, add a Call method node and pick the method, or a Method timer to run it on an interval.
  • Methods are shared automatically when a macro that uses them is exported.

Condition modes

The Condition node asks you to pick a Mode first; each mode shows only its own settings.

ModeSettingsOutputs
WarframeState: running / closedtrue / false
NodesNodes to watch + Match (any/all)true / false
OCRCompare (contains / equals / not_contains) + Valuetrue / false
SwitchCases, one per output1, 2, 3 … + else

The OCR mode only appears when a Read text (OCR) node is connected into the Condition node. Cases in Switch mode use the form kind:argument, e.g. ocr_contains:Heat or warframe_closed.

Pickers (window / region)

  • Window picker (Focus window): press Pick window, then activate the target window during the 3-second countdown. It records that window's process and title.
  • Region picker (Read text — OCR): press Pick region to open a fullscreen overlay; drag a box over anything on screen. Esc cancels.
  • Position picker (Move mouse): press Pick position, then click anywhere to capture that point.

Focus window

Brings a window to the foreground, nudges the cursor near its centre and clicks once.

FieldMeaning
ProcessExecutable name to focus, e.g. Warframe.x64 or notepad.
Window title (optional)If set, matches a visible window whose title contains this text instead.

Use the Pick window button to fill both automatically.

Read text (OCR)

The Read text (OCR) node captures a screen region and reads its text with a bundled, pure-Rust engine (models embedded — nothing to install).

It's controlled by pub const OCR_ENABLED: bool = true; in src-tauri/src/workflow.rs (set it to false to hide the node).

Settings (grouped)

  • Region — X / Y / Width / Height (with the region picker).
  • Preprocessing — Invert (auto/on/off), Upscale, Binarize (Otsu).
  • Colour filter — Only colour (e.g. #bd2a2a) + tolerance; isolates text of that colour.
  • Characters — Only characters, e.g. 0123456789.%+-.
  • Model — optional local detection/recognition model paths (.onnx/.rten).

The result is always sent to the next nodes: read it in a Condition (OCR mode) or inject it elsewhere with {{ocr}}. The node also shows the last recognised text.

Sharing & importing

  1. Open a macro and click Share / Import macro.
  2. Export — copy the share code (includes every method the macro uses).
  3. Import — paste a share code (or raw JSON) and press Import macro.

Imported macros are added as new macros; method id conflicts are remapped so nothing is overwritten.

Hotkey & tray

  • Set a global hotkey in the sidebar (modifier + key, default F3) to start/stop the selected macro from anywhere.
  • The app keeps running in the system tray; closing the window hides it. Use the tray menu to Quit.
  • Launching SleepFrame again focuses the existing window (single instance).

Troubleshooting

The macro doesn't seem to do anything

  • Make sure the game window is focused — add a Focus window node first.
  • If the game is running elevated, Windows blocks synthetic input; run the game without admin.
  • Run SleepFrame as administrator if your game is elevated.

Clicks don't register in-game

  • Clicks are held briefly to help games register them. Try focusing the window right before the click.

Where are my macros stored?

%APPDATA%\com.sleepframe.app\settings (built-in macros can be reset; your edits shadow the defaults).

OCR is missing

It's disabled by default — see the OCR section to enable it.
